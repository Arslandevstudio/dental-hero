# Dental hero — стеклянный моляр на холме

Hero-экран лендинга стоматологии. Стек: Vite + three.js, без фреймворков.

**Сайт:** https://arslandevstudio.github.io/dental-hero/ (собирается и публикуется GitHub Actions при каждом push в `main`, см. `.github/workflows/deploy.yml`).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # → dist/
```

## Из чего состоит

| Файл | Что делает |
| --- | --- |
| `scripts/build-tooth.mjs` | Генерирует моляр → `public/models/tooth.bin`. SDF (коронка-суперэллипсоид, 4 бугра через smooth union, крестовая фиссура мягким вычитанием, шейка, 4 корня-трубки по кривым Безье), затем marching cubes (200 ячеек по высоте) и 20 итераций сглаживания Тобина (λ 0.5, μ −0.53). Все стыки сшиты smooth-min с k 0.12–0.17. В браузере выполняются `mergeVertices()` и `computeVertexNormals()`, затенение гладкое. |
| `scripts/build-bg.mjs` | Вырезает небо из фото → `public/bg/sky.jpg`, `sky-sm.jpg` |
| `src/background.js` | Одна функция `bgColor(направление)`: фото неба, процедурные размытые горы, долина. По ней рисуется задник (запекается в текстуру при ресайзе) и строится envMap для отражений, поэтому отражения в стекле совпадают с фоном |
| `src/ground.js` | Холм (`hillY`), 3D-трава с ветром, жёлтые и белые цветы |
| `src/tooth.js` | Загрузка меша и стекло (`MeshPhysicalMaterial`: transmission 1, thickness 0.9, ior 1.45, roughness 0.05, dispersion 0.04, clearcoat 1 с clearcoatRoughness 0.1, iridescence 0.1). Мягкий френель: у силуэта смещение преломления плавно гасится, и край перетекает в фон. Тонмаппинг ACES (экспозиция 0.8) применяется только к стеклу |
| `src/main.js` | Кадрирование, анимация (±15° за 8 с, параллакс от мыши), адаптивное качество |
| `index.html`, `src/style.css` | Текст, логотип, кнопка. Зуб вписывается в невидимый блок `.tooth-slot`: двигайте его в CSS, и камера подстроится сама |

## Форма зуба

Параметры лежат в начале `scripts/build-tooth.mjs`: `CROWN`, `CUSPS`, `GROOVE_*`, `NECK`, `ROOT_*`, `rootPath()`.

- `npm run tooth -- --preview scratch/prev.png`: быстрый рендер SDF в четырёх видах (спереди, сбоку, 3/4, сверху) примерно за 25 с.
- `npm run tooth`: собрать меш, 3–5 минут (`--res 256` даст ещё плотнее, но дольше и тяжелее файл).

## Параметры URL для отладки

| Параметр | Что делает |
| --- | --- |
| `?still` | заморозить анимацию |
| `?yaw=38` | базовый поворот зуба (градусы) |
| `?clay` | матовый материал |
| `?chrome` | зеркальный материал, на нём видна любая рябь в нормалях |
| `?q=0/1/2` | принудительный уровень качества |

По умолчанию качество подбирается само. Если первые ~60 кадров идут медленнее 40 fps, буфер преломления уменьшается, стекло становится односторонним, травы становится меньше, а dispersion и iridescence отключаются.
